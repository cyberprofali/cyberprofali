## 👋 About Me

I'm a cybersecurity leader, researcher, educator, and hands-on security practitioner with experience spanning **cybersecurity consulting, offensive security, enterprise risk management, security research, systems, and computer science education**.

I currently work in **vCISO and cybersecurity leadership**, helping organizations translate complex technical risks into actionable security strategy, governance, program improvements, and executive-level decisions.

My technical roots are in **penetration testing and offensive security**, while my broader interests extend into operating systems, Linux, security engineering, automation, cloud computing, artificial intelligence, and low-level systems.

I enjoy working across the full security stack — from understanding how systems fail technically to determining how organizations should manage that risk strategically.

- 🔐 **vCISO & Cybersecurity Leader**
- ⚔️ Offensive security and penetration-testing background
- 🧠 Interested in **operating systems, reverse engineering, exploit development, and low-level computing**
- 🏗️ Experience with **security architecture, GRC, risk assessments, and security program development**
- 🔬 Background in **computer science research and high-performance computing**
- 🎓 Computer science and cybersecurity **educator and mentor**
- 🐧 Linux and open-source enthusiast
- ⚙️ Interested in **security engineering and automation**
- 🤖 Exploring **AI, agents, RAG, and AI-assisted cybersecurity workflows**
- ☁️ Experience across AWS, Azure, and Google Cloud
